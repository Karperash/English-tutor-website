# EnglishTutor — PHP без фреймворков

Учебный, но полноценный сайт для онлайн-репетитора английского. Backend написан на чистом PHP, база — MySQL, запуск — Docker Compose.

## Что уже работает

- публичная главная: «Обо мне», стоимость, отзывы, контакты;
- вход по логину/паролю, без самостоятельной регистрации;
- две роли: `teacher` и `student`;
- предсозданный аккаунт преподавателя;
- создание, редактирование и удаление учеников;
- данные ученика: имя, фамилия, логин, пароль, телефон, имя и телефон родителя;
- создание преподавапшетелем свободных слотов по 60 минут;
- запись ученика на занятие;
- максимум 3 активных занятия на одну неделю;
- запись не позднее чем за 12 часов;
- отмена учеником не позднее чем за 3 часа;
- перенос и отмена занятия преподавателем;
- флажок ученика «Могу также» на других свободных слотах (не бронирует время);
- ссылка на онлайн-урок + комментарий о платформе;
- отметка оплаты преподавателем (`Оплачено / Не оплачено`);
- домашние задания;
- загрузка DOC, DOCX, JPG, PNG, WEBP;
- отправка домашней работы учеником;
- проверка и комментарий преподавателя;
- приватные заметки преподавателя об ученике;
- внутренние уведомления;
- адаптивный интерфейс для телефона и компьютера;
- CSRF, PDO prepared statements, хеширование паролей, проверка ролей;
- файлы домашней работы находятся вне `public` и скачиваются только после проверки доступа.

## Запуск через Docker

### 1. Открой папку проекта в терминале

Windows PowerShell:

```powershell
cd путь\к\english-tutor-php
```

### 2. Собери и запусти контейнеры

```powershell
docker compose up --build
```

Первый запуск скачает образы PHP, Composer и MySQL и создаст базу данных.

### 3. Открой сайт

```text
http://localhost:8080
```

Страница входа:

```text
http://localhost:8080/login
```

### 4. Войди как преподаватель

```text
Логин: Katy1009
Пароль: loveyou
```

## Как проверить основной сценарий

1. Войти как `Katy1009`.
2. Открыть «Ученики» → «Добавить ученика».
3. Создать ученику логин и пароль.
4. Открыть «Расписание».
5. Добавить несколько будущих слотов (важно: минимум через 12 часов, если потом будешь записываться как ученик).
6. Выйти из аккаунта учителя.
7. Войти под созданным учеником.
8. Открыть «Расписание» и записаться на слот.
9. Отдельно отметить другой слот кнопкой «Могу также».
10. Выйти и снова зайти учителем.
11. В расписании открыть занятое занятие.
12. Добавить ссылку Google Meet / Zoom и комментарий.
13. Поставить отметку оплаты.
14. Выдать домашнее задание и при необходимости прикрепить файл.
15. Зайти учеником, открыть задание, отправить комментарий и файл.
16. Зайти учителем и проверить работу.

## Важные правила расписания

### Продолжительность

Все занятия автоматически создаются на 60 минут.

### Запись

Ученик не может записаться, если до начала меньше 12 часов.

### Лимит

На одну календарную неделю (понедельник–воскресенье) ученик может иметь максимум 3 запланированных занятия.

### Отмена

Ученик может самостоятельно отменить занятие только если до начала больше 3 часов.

После отмены слот снова становится свободным.

### «Могу также»

Эта кнопка НЕ бронирует занятие. Она только показывает преподавателю, что ученик может заниматься в этот день и время.

## База данных

MySQL внутри Docker доступен приложению по имени хоста `db`.

Для подключения к базе с компьютера:

```text
Host: localhost
Port: 3307
Database: english_tutor
User: tutor
Password: tutorpass
```

Локальные значения находятся в `.env` и предназначены только для разработки.

## Если нужно полностью пересоздать базу

Остановить контейнеры и удалить volume базы:

```powershell
docker compose down -v
```

После этого:

```powershell
docker compose up --build
```

ВНИМАНИЕ: `down -v` удалит все созданные тестовые данные.

## Если порт 8080 занят

В `docker-compose.yml` изменить:

```yaml
ports:
  - "8080:80"
```

например на:

```yaml
ports:
  - "8081:80"
```

После этого сайт будет на `http://localhost:8081`.

## Часовой пояс

В `.env`:

```env
APP_TIMEZONE=Europe/Berlin
```

При необходимости можно заменить, например, на:

```env
APP_TIMEZONE=Europe/Moscow
```

После изменения перезапусти контейнеры.

public/          единственная публичная директория
  assets/        CSS и JS

## Полезные команды

Запуск:

```powershell
docker compose up
```

Запуск в фоне:

```powershell
docker compose up -d
```

Остановка:

```powershell
docker compose down
```

Логи PHP/Apache:

```powershell
docker compose logs -f app
```

Логи MySQL:

```powershell
docker compose logs -f db
```

PHP shell внутри контейнера:

```powershell
docker compose exec app bash
```

Проверка окружения, базы и аккаунта преподавателя:

```powershell
docker compose exec app php scripts/self-check.php
```

В норме все строки должны начинаться с `[OK]`.
